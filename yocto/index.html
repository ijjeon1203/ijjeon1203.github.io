Yocto Project
    ├── Poky          ← 레퍼런스 배포판 (빌드 시스템 포함)
    ├── BitBake       ← 빌드 엔진 (make 같은 것)
    ├── OpenEmbedded  ← 레시피 모음
    └── Layer         ← 기능별 모듈 단위

layer 구조

met+a/              ← OpenEmbedded 기본 레이어
meta-poky/         ← Poky 배포판 레이어
meta-nxp/          ← NXP i.MX 보드 지원
meta-variscite/    ← Variscite 보드 커스텀
meta-myapp/        ← 내가 만드는 앱 레이어
