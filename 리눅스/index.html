리눅스 서버에서 GUI(그래픽 사용자 인터페이스)를 사용하는 것은 일반적으로 서버 환경에서 필요하지 않지만, 특정 작업을 위해 GUI가 필요할 수 있습니다. 예를 들어, 서버 관리, 애플리케이션 개발, 또는 데스크탑 환경에서처럼 편리한 작업을 하려는 경우입니다. 서버에서 GUI를 설정하려면 몇 가지 선택지가 있습니다.

1. Xfce

  • 경량화된 데스크탑 환경으로, 서버 리소스를 많이 사용하지 않으면서도 기본적인 GUI를 제공합니다.

  • 설치 명령:

    sudo apt update
sudo apt install xfce4 xfce4-goodies

  • 특징:

    • 가벼운 리소스 사용
    • 직관적인 인터페이스
    • 다양한 애플리케이션과 잘 통합됨

2. LXQt

  • 또 다른 경량 데스크탑 환경으로, LXDE의 후속 버전입니다. 매우 적은 시스템 자원을 사용하면서도 직관적인 GUI를 제공합니다.

nmcli

  • 리눅스에서 NetworkManager를 커맨드라인으로 제어하는 도구
  • GUI 없이 네트워크 연결(Wi-Fi, 이더넷, VPN 등)을 설정하고 관리
# 전체 네트워크 상태 확인
nmcli general status

# 연결된 장치 목록
nmcli device status

# Wi-Fi 목록 스캔
nmcli device wifi list

# Wi-Fi 연결
nmcli device wifi connect "SSID이름" password "비밀번호"

# 현재 연결 목록 확인
nmcli connection show

# 특정 연결 활성화/비활성화
nmcli connection up "연결이름"
nmcli connection down "연결이름"

# IP 정보 확인
nmcli device show eth0

# 고정 IP 설정 (예시)
nmcli connection modify "연결이름" ipv4.addresses 192.168.1.100/24
nmcli connection modify "연결이름" ipv4.gateway 192.168.1.1
nmcli connection modify "연결이름" ipv4.dns 8.8.8.8
nmcli connection modify "연결이름" ipv4.method manual
nmcli connection up "연결이름"
