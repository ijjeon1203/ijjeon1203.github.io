리눅스 파일 시스템 계층 구조(FHS) 이해

리눅스는 “모든 것이 파일이다"라는 철학을 가지고 있습니다. 어디에 무엇이 있는지 아는 것이 중요합니다.경로역할/etc시스템 설정 파일 (설정 바꿀 때 가장 많이 방문)/var/log시스템 및 앱의 로그 (에러 원인 찾을 때 필수)/home사용자별 개인 파일 (현재 작업 중인 workspace가 위치할 곳)/bin, /usr/bin실행 가능한 명령어 프로그램들이 모여 있는 곳

  1. “파이프(|)와 리다이렉션(>)” 마스터하기 여러 명령어를 조합해서 강력한 기능을 만드는 리눅스의 꽃입니다.

grep: 텍스트 검색. (예: ls -R | grep “post” -> 모든 하위 폴더에서 post가 포함된 파일 찾기)

tail -f: 로그 파일을 실시간으로 모니터링할 때 씁니다.

리다이렉션: ls > file_list.txt라고 치면 화면에 나올 내용이 파일로 저장됩니다.

  1. 패키지 관리자와 친해지기 Windows처럼 설치 프로그램을 다운로드받는 게 아니라, 명령어로 관리하는 습관을 들이세요.

Ubuntu 계열: sudo apt update && sudo apt install [패키지명]

CentOS 계열: sudo yum install [패키지명]

내가 필요한 도구(git, hugo, python 등)를 명령어로 직접 설치하고 버전 관리까지 해보는 경험이 중요합니다.

  1. 도움말(man)을 읽는 습관 모르는 명령어가 나오면 구글링도 좋지만, 터미널에 man [명령어]를 쳐보세요. 해당 명령어의 공식 설명서가 나옵니다.

“구글은 정답을 알려주지만, man page는 원리를 알려줍니다.”
