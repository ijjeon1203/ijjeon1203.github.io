리눅스s

리눅스 구조

etc

  • systemd : 리눅스의 초기화 시스템 또는 데몬시스템
  • 이전에는 system5

boot

  • 컴퓨터가 켜질 때 가장 먼저 읽히는 곳
  • 새로 빌드한 커널 이미지나 DTB(Device Tree Blob) 파일을 여기에 복사하여 시스템에 반영

usr (Unix System Resources)

  • 프로그램의 창고(사용자가 설치한 대부분의 프로그램 정보)

/usr/bin: 일반 사용자가 실행하는 대부분의 명령어(python, gcc 등).

/usr/lib: 프로그램 실행에 필요한 공유 라이브러리.

/usr/local: 사용자가 소스 코드를 직접 컴파일해서 설치할 때 사용하는 공간.

외부 연결

/mnt: 관리자가 수동으로 파일 시스템을 마운트할 때 쓰는 임시 공간입니다. (예: mount /dev/sdb1 /mnt) /media: USB나 외장하드를 꽂았을 때 OS가 자동으로 인식해서 연결해주는 곳입니다. (예: /media/user/usb_name)
