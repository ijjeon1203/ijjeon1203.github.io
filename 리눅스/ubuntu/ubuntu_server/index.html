Ubuntu server

서버는 일반적으로 랙 마운트 타워의 두 가지 폼 팩터로 제공

타워 서버는 기본적으로 데스크탑이지만 수명, 안정성 및 보안에 중점을 둔 부분이 종종 다릅니다. 예를 들어, 서버는 오류 코드 수정 (ECC) RAM을 사용합니다. 서버가 아닌 데스크톱은 그렇지 않습니다.

또한 서버에는 모니터, 키보드 및 마우스와 같은 주변 장치가 반드시 포함되어 있지는 않습니다. 주변 장치없이 서버를 실행하는 것을 “헤드리스"설정이라고합니다. 서버용 소프트웨어에는 운영 체제, 서버 소프트웨어 (예 : 웹 사이트 호스팅 용 Apache, CUPS 인쇄 서버) 및 보안 소프트웨어가 포함됩니다.

Ubuntu에는 안정적인 릴리스와 LTS (장기 서비스) 반복이라는 두 가지 고유 한 특징

Ubuntu Desktop과 Ubuntu Server의 차이

그래픽 사용자 인터페이스 Ubuntu Desktop 및 Server의 주요 차이점은 데스크탑 환경 Ubuntu Desktop에는 그래픽 사용자 인터페이스가 포함되어 있지만 Ubuntu Server에는 없습니다.

대부분의 서버가 헤드리스로 실행되기 때문입니다. 그러나 이것은 무엇을 의미합니까? 글쎄, 그들은 기계와 상호 작용하기 위해 전통적인 키보드, 마우스 및 모니터 설정없이 실행됩니다. 대신 서버는 일반적으로 SSH를 사용하여 원격으로 관리됩니다. SSH는 Unix 기반 운영 체제에 내장되어 있지만 Windows에서 SSH 를 사용하는 것도 간단합니다.

일부 Linux 서버 운영 체제에는 데스크탑 환경이 있지만 대부분은 GUI가 없습니다. 따라서 Ubuntu Desktop은 컴퓨터가 비디오 출력을 사용

Ubuntu 데스크탑 및 서버의 다양한 애플리케이션 또한 Ubuntu Desktop에는 일반 용도에 적합한 응용 프로그램이 포함되어 있습니다. 사무실 생산성 제품군, 멀티미디어 소프트웨어 및 웹 브라우저가 있습니다.

그러나 Ubuntu Server에는 다른 패키지도 포함되어 있습니다. 이들은 서버 요구 사항에 중점을 둡니다. 따라서 Ubuntu Server는 이메일 서버, 파일 서버, 웹 서버 및 삼바 서버로 실행될 수 있습니다. 특정 패키지에는 Bind9 및 Apache2가 포함됩니다. Ubuntu 데스크톱 응용 프로그램은 호스트 컴퓨터에서 사용하는 데 중점을 두는 반면 Ubuntu Server 패키지는 보안뿐 아니라 클라이언트와의 연결을 허용하는 데 중점을 둡니다.

Ubuntu Server 및 데스크탑 설치의 차이점 Ubuntu Server에는 GUI가 없기 때문에 Ubuntu Desktop의 설치와 다릅니다. Ubuntu Desktop을 설치하는 것은 본질적으로 다른 소프트웨어 설치와 같습니다. 그러나 Ubuntu Server는 대신 프로세스 중심 메뉴를 사용합니다.

Ubuntu Server vs 데스크탑 성능 Ubuntu Server에는 기본적으로 GUI가 없기 때문에 잠재적으로 더 나은 시스템 성능을 제공합니다. 결국 관리 할 데스크톱 환경이 없으므로 리소스를 서버 작업 전용으로 사용할 수 있습니다.

그러나 이것이 항상 실제로 작동하는 것은 아닙니다. 예를 들어 특히 리소스를 많이 사용하는 서버 소프트웨어를 설치하여 시스템 속도를 저하시킬 수 있습니다. 반대로 순전히 워드 프로세싱을 위해 Ubuntu Desktop을 사용할 수 있습니다.

유사점

데스크톱이 아닌 Ubuntu Server를 사용하는 것이 완전히 새로운 경험은 아닙니다. 최소한 명령 줄과 SSH에 대한 경험이 있다면 Ubuntu Server가 익숙해 보일 것입니다. 다른 주요 유사점 : 커널 및 지원이 있습니다.

Ubuntu Desktop과 Ubuntu Server는 다른 커널입니까? 아니요. Ubuntu 12.04 이후로 서버 및 데스크톱 버전은 모두 동일한 커널을 사용합니다. Ubuntu Desktop과 Ubuntu Server는 모두 동일한 커널을 사용하기 때문에 두 변형에 패키지를 추가 할 수 있습니다. 즉, 기본 설치간에 차이가 있지만 그에 따라 Ubuntu 플레이버를 사용자 지정할 수 있습니다.

따라서 헤드리스로 실행할 수 없다고 결정한 경우 Ubuntu Server로 시작하여 데스크톱 환경을 설치할 수 있습니다. 또는 Ubuntu Desktop으로 시작하여 필요한 패키지를 추가하여 서버를 만들 수 있습니다. Ubuntu Server 및 Desktop은 핵심 Ubuntu 커널을 공유하므로 기본 설치 차이가 향후 소프트웨어 패키지 설치를 배제하지 않습니다.

Ubuntu Server 및 Desktop Edition 지원에 차이가 있습니까? 다시 말하지만. Ubuntu 12.04 LTS 이전에는 데스크톱 버전의 지원주기가 3 년이었습니다. 해당 서버는 5 년 지원주기의 혜택을 받았습니다.

12.04 LTS 출시 이후 Ubuntu Desktop 및 Server 변형은 모두 5 년 지원 주기로 이동했습니다.

Ubuntu Server vs Ubuntu Desktop : 어떤 것을 사용해야합니까? 차이점과 유사점을 고려할 때 이제 큰 질문이 있습니다. Ubuntu Server 또는 Ubuntu Desktop을 사용해야합니까? Ubuntu의 LTS 버전을 사용하는 한 서버 또는 데스크톱이 서버로 작동해야합니다.

둘을 구분하는 주요 요소는 GUI와 기본 패키지로 남아 있습니다. 그래도 핵심 Ubuntu 커널은 두 버전 모두에 동일한 패키지를 설치할 수 있음을 의미합니다.

Ubuntu Desktop을 사용하는 경우 컴퓨터를 일일 드라이버로 사용하는 경우 Ubuntu Desktop을 사용해야합니다. 여기에는 다양한 멀티미디어 및 생산성 소프트웨어가 포함됩니다. GUI가 있고 설치가 매우 간단합니다. 또한 서버 소프트웨어를 설치하여 Ubuntu 데스크탑을 서버로 사용할 수 있습니다.

예를 들어 Ubuntu Desktop과 함께 저전력 Lenovo ThinkServer TS140을 실행할 수 있습니다. 이것은 모니터를 연결하고 데스크탑 환경을 사용하는 옵션을 제공합니다. Linux 미디어 서버 소프트웨어를 사용 하여 Ubuntu Server를 홈 시어터 PC (HTPC)로 변환 할 수 있습니다. 이에 대한 좋은 옵션에는 Plex 및 Subsonic이 포함됩니다. 또는 Ubuntu Server 대신 Ubuntu Desktop을 사용하여 Linux 게임 서버 를 만들 수도 있습니다.

Ubuntu Server는 서버에 가장 적합합니다. 당연해 보일 수 있습니다. 그러나 랙 마운트 및 타워 서버가있는 것처럼 모든 서버가 동일한 것은 아닙니다. 서버를 헤드리스로 실행하려는 경우 Ubuntu Desktop 대신 Ubuntu Server를 선택해야합니다. 두 Ubuntu 버전은 코어 커널을 공유하므로 나중에 언제든지 GUI를 추가 할 수 있습니다.

또한 Ubuntu Server는 패키지가 포함 된 특정 종류의 서버에 가장 적합합니다. 예를 들어 이메일 서버 또는 웹 서버를 만들 때 Ubuntu Server를 고려할 수 있습니다.

따라서 프로젝트에 덜 효과적인 옵션을 선택하십시오. Ubuntu Server에 필요한 패키지가 포함 된 경우 Server를 사용하고 데스크톱 환경을 설치합니다. GUI가 꼭 필요하지만 기본 서버 설치에 포함되지 않은 서버 소프트웨어를 원하십니까? 음, Ubuntu Desktop을 사용하고 필요한 소프트웨어를 설치하십시오.

관련 : Ubuntu 대 CentOS

Ubuntu Core는 임베디드 장치 프로젝트를위한 Linux의 제거 된 버전입니다. 이것은 사물 인터넷 장치 또는 스마트 홈 프로젝트 일 수 있습니다. Ubuntu Core는 서버 기능을 가질 수 있지만 Ubuntu Server를 실행하는 컴퓨터와 같은 방식으로 서버가 아닙니다.

Ubuntu 데스크탑과 서버 사이에서 올바른 선택을하십시오 궁극적으로 서버에 Ubuntu Server를 사용하고 데스크톱에 Ubuntu Desktop을 사용하는 것만 큼 간단하지 않습니다. 기계 설정과 관련된 작업과 요구 사항을 고려하십시오. 미디어 서버를 실행하는 경우 Ubuntu Server가 과도 할 수 있습니다. 일반적인 사용을위한 데스크탑은 Ubuntu Desktop을 실행해야합니다.

대부분의 경우 가장 쉬운 초기 설정이 필요한 옵션에 대한 의사 결정 센터가 있습니다. 하지만 친숙 함도 고려해야합니다. 서버를 설정하고 GUI없이 불편한 경우 Ubuntu Desktop을 사용하십시오. 서버를 만드는 것은 위협적인 것처럼 들릴 수 있습니다. 데스크톱 환경에서 시작하면 덜 부담스러운 작업이 될 수 있습니다.
