`.tgz` 또는 `.tar.gz` 파일을 압축 해제하지 않고 내부 목록만 확인할 수 있습니다.

### Linux

```bash
tar -tzf 파일명.tgz
```

예시:

```bash
tar -tzf backup.tgz
```

### 자세한 정보 포함

```bash
tar -tvzf backup.tgz
```

출력 예:

```text
drwxr-xr-x root/root         0 2026-06-24 10:00 project/
-rw-r--r-- root/root      1024 2026-06-24 10:01 project/main.c
-rw-r--r-- root/root       512 2026-06-24 10:01 project/Makefile
```

### 특정 파일 검색

```bash
tar -tzf backup.tgz | grep Makefile
```

### 파일 개수 확인

```bash
tar -tzf backup.tgz | wc -l
```

### 용량 큰 파일 찾기

```bash
tar -tvzf backup.tgz | sort -k3 -n
```

Jetson이나 일반 Linux에서라면 `tar -tzf 파일명.tgz`만으로 내부 디렉터리 구조를 확인하는 경우가 가장 많습니다.
네, 압축 안에 있는 특정 파일이나 폴더만 골라서 풀 수 있습니다.

먼저 내부 목록 확인:

```bash
tar -tzf archive.tgz
```

예를 들어 결과가:

```text
project/
project/main.c
project/src/test.c
project/Makefile
```

라면,

### 특정 파일만 압축 해제

```bash
tar -xzvf archive.tgz project/sidebar.c
```

### 특정 폴더만 압축 해제

```bash
tar -xzvf archive.tgz project/src/
```

### 현재 디렉토리가 아닌 다른 위치에 풀기

```bash
tar -xzvf archive.tgz -C /tmp project/sidebar.c
```

### 와일드카드 사용 (GNU tar)

```bash
tar -xzvf archive.tgz --wildcards "*.c"
```

또는

```bash
tar -xzvf archive.tgz --wildcards "*/Makefile"
```

만약 파일명이 정확히 기억 안 나면:

```bash
tar -tzf archive.tgz | grep 파일명
```

으로 먼저 찾은 뒤 그 경로를 그대로 `tar -xzvf` 뒤에 붙이면 됩니다.


네, 가능합니다.

예를 들어:

```text
/home/user/work/a.tar
```

가 있을 때,

```text
/home/user/work/a/
```

디렉터리를 만들고 그 안에 압축을 풀고 싶다면:

```bash
mkdir -p "$(dirname a.tar)/$(basename a.tar .tar)"
tar -xvf a.tar -C "$(basename a.tar .tar)"
```

좀 더 간단히 현재 디렉터리 기준이라면:

```bash
mkdir -p a
tar -xvf a.tar -C a
```

`.tgz`나 `.tar.gz`까지 고려하면:

```bash
file="a.tar.gz"
dir=$(basename "$file" .tar.gz)

mkdir -p "$dir"
tar -xzvf "$file" -C "$dir"
```

범용적으로 처리하려면:

```bash
file="a.tgz"
dir="${file%%.*}"

mkdir -p "$dir"
tar -xvf "$file" -C "$dir"
```

### 주의

압축 파일 내부가 이미:

```text
a/
 ├─ src/
 └─ Makefile
```

형태라면

```bash
mkdir a
tar -xvf a.tar -C a
```

결과가:

```text
a/
 └─ a/
     ├─ src/
     └─ Makefile
```

처럼 `a/a`가 될 수 있습니다.

그래서 먼저 확인하는 습관이 좋습니다.

```bash
tar -tf a.tar | head
```

첫 줄이 `a/` 같은 최상위 디렉터리면 그냥 풀고,

```bash
src/
Makefile
README.md
```

처럼 바로 파일이 나오면 별도 디렉터리를 만들어서 `-C`로 푸는 것이 깔끔합니다.


폴더를 `.tgz`(=`.tar.gz`)로 압축하는 방법입니다.

예를 들어 `project` 폴더를 압축하려면:

```bash
tar -czvf project.tgz project/
```

옵션 의미:

* `c` : 새 tar 생성(Create)
* `z` : gzip 압축
* `v` : 진행 내용 출력(Verbose)
* `f` : 파일명 지정(File)

결과:

```text
project.tgz
```

생성됨.

### 현재 디렉터리의 폴더 압축

```bash
tar -czvf backup.tgz my_folder/
```

### 여러 파일/폴더 함께 압축

```bash
tar -czvf source.tgz src/ include/ Makefile README.md
```

### 진행 내용 없이 압축

실무에서는 보통 `v`를 빼고 사용합니다.

```bash
tar -czf project.tgz project/
```

### 압축 내용 확인

```bash
tar -tzf project.tgz
```

### 압축 해제

```bash
tar -xzf project.tgz
```

만약 **폴더 자체는 제외하고 내부 파일들만 압축**하고 싶다면:

```bash
cd project
tar -czf ../project.tgz .
```

그러면 압축을 풀었을 때 `project/` 폴더가 생성되지 않고 파일들이 바로 풀립니다. 이 차이는 배포용 패키지를 만들 때 꽤 중요합니다.


`.tar` 파일 압축 해제는 다음과 같습니다.

### 기본 압축 해제

```bash
tar -xvf a.tar
```

옵션:

* `x` : 압축 해제(eXtract)
* `v` : 진행 내용 출력
* `f` : 파일 지정

### 특정 폴더에 압축 해제

```bash
mkdir -p a
tar -xvf a.tar -C a
```

### 내부 목록만 확인

```bash
tar -tf a.tar
```

### 특정 파일만 압축 해제

```bash
tar -xvf a.tar path/to/file
```

---

참고로 확장자별 명령은 다음과 같습니다.

| 파일 형식         | 압축 해제                |
| ----------------- | ------------------------ |
| `.tar`            | `tar -xvf file.tar`      |
| `.tar.gz`, `.tgz` | `tar -xzvf file.tgz`     |
| `.tar.bz2`        | `tar -xjvf file.tar.bz2` |
| `.tar.xz`         | `tar -xJvf file.tar.xz`  |

요즘 GNU tar는 자동 감지를 지원해서 아래처럼 써도 대부분 됩니다.

```bash
tar -xvf file.tgz
tar -xvf file.tar.gz
tar -xvf file.tar.xz
```

그래도 호환성을 위해 `.tgz`는 `-xzf`를 많이 사용합니다.
