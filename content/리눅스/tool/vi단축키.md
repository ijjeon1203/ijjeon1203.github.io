vi 단축키
명령모드 (esc 눌렀을때, vi 처음 들어갔을때)
파일의 끝으로 이동할때는 - G
한줄 잘라내기 - dd
세줄 잘라내기 - 3dd
붙여넣기 - p
한글자 삭제 - x
단어 삭제 - dw
실행취소! - u
줄의 맨 앞 - o
줄의 맨 뒤 - $
(G, $ 이거 개꿀)
마지막행 모드 (esc -> : 눌렀을때)
(명령어 뒤에 !를 붙이면 강제로 수행하니까, vi가 궁시렁 궁시렁 거리면 " ! "붙여서 실행)
저장만 : w
종료만 : q
저장 후 종료 : wq
라인 번호좀 보자 : set nu
커서 위치 뒤로 문자열좀 찾자 : ?문자열
커서 위치 앞으로 문자열좀 찾자 : /문자열
(set nu, wq! 개꿀)
