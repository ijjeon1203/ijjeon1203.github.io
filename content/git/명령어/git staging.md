git add로 새버전이 git 데이터베이스에추가

staging area
파일을 올린후커밋하기 전까지 새 버전이 대기하는 장소 
- 다른 사람과 공유되거난 동기화 되지 않으며 오직 로컬 컴퓨터에만 존재 

스테이징시 일어나는일

1.  git은 그 파일의 스냅샷을 데이터베이스에 저장해 다음 커밋할 때 참조될 수 있게함

git에선 본질적으로 파일이 참조될 수 있도록 이미 저장소에 존재해야함
커밋할 때 반드시 참조돼야함

파일의버전이 스테이징되기전에는 gitㅡㅇㄴ 그 버전을 알 수 없으며 따라서 커밋도 할 수 없음 

2. git은 다음 커밋의 로컬초안을 작성 
- 안에 있는 모든 파일과 디렉터리 참조가 포함 
공교롭게도 이전 커밋으로부터 덮어쓰거나 변경되지않은 파일의 참조도 포함 
모든커밋은 보수적
단지변경된 대상만참조하지않고 특정시점에서 프로젝트의 상태를 구성하는 모든 것을 참조
